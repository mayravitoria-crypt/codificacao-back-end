# Codificação Back-End

## Sobre a disciplina

Este repositório foi criado para armazenar as atividades, exercícios e projetos desenvolvidos durante a disciplina de Codificação Back-End.

## Objetivos

* Compreender os fundamentos do desenvolvimento Back-End;
* Desenvolver aplicações utilizando JavaScript e Node.js;
* Conhecer conceitos de APIs e servidores;
* Trabalhar com gerenciamento de dependências;
* Aplicar boas práticas de programação;
* Utilizar o Git e o GitHub para versionamento dos projetos.

## Tecnologias utilizadas

* JavaScript
* Node.js
* NestJS
* APIs REST
* Git
* GitHub

## Ferramentas utilizadas

* Visual Studio Code
* Node.js
* Git
* GitHub
* Terminal/CMD

## Organização

O repositório será utilizado para armazenar as atividades e projetos realizados durante a disciplina de Codificação Back-End.
