# Codificação Back-End

## Sobre a disciplina

Este repositório foi criado para armazenar as atividades, exercícios e projetos desenvolvidos durante a disciplina de Codificação Back-End.

## Objetivos do curso

A disciplina tem como objetivo desenvolver conhecimentos e habilidades relacionados ao desenvolvimento de aplicações Back-End, compreendendo a lógica de programação, a criação de aplicações, o funcionamento de servidores e a comunicação entre diferentes sistemas.

Durante o curso, serão desenvolvidos conhecimentos sobre:

* Desenvolvimento Back-End;
* Lógica de programação;
* Criação e consumo de APIs;
* Comunicação entre aplicações;
* Manipulação e armazenamento de dados;
* Banco de dados;
* Estruturação e organização de projetos;
* Boas práticas de desenvolvimento.

## Tecnologias aplicadas

Durante o desenvolvimento das atividades serão utilizadas tecnologias e conceitos relacionados ao desenvolvimento Back-End, como:

* JavaScript;
* TypeScript;
* Node.js;
* APIs REST;
* Banco de dados;
* HTTP;
* Git;
* GitHub.

## Ferramentas utilizadas

As principais ferramentas utilizadas durante a disciplina são:

* Visual Studio Code;
* Git;
* GitHub;
* Terminal;
* Node.js;
* Navegador Web.

## Desenvolvimento

Este repositório será utilizado ao longo da disciplina para registrar e versionar as atividades práticas e projetos desenvolvidos, permitindo acompanhar a evolução dos conhecimentos em desenvolvimento Back-End.
